# Phase-D visualization reference registry

This repository-only directory is the persistent evidence surface for ocean,
climate and Earth-system visualization decisions. Every external source
materially used to justify a visualization architecture, renderer, palette,
API, scientific-presentation rule, or implementation decision **must** be
entered in `visualization-reference-registry.csv`. A citation that exists only
in chat history, a temporary prompt, or personal notes is not admissible Phase-D
evidence.

`visualization-tool-registry.csv` records the systems and R packages evaluated;
`visualization-design-exemplars.csv` records the nine user-provided concepts as
design inspiration only. A design exemplar is not a scientific specification.

The registry stores bibliographic facts, DOI/URL, any supplied filename, and
review notes. No paper PDF, article figure, screenshot, tile, or other
copyrighted binary is redistributed here unless reuse rights are independently
verified. The D1A validator enforces unique IDs, required sources, referential
integrity, and the absence of copied PDFs.

Access date for the D1A review is 2026-09-05. Package versions and release dates
are observations at that date, not compatibility promises.
